# Contributing

Thanks for helping improve tinytrace.

1. Open an issue describing the problem or proposal.
2. Fork the repository and create a topic branch.
3. Add tests for behaviour changes.
4. Run `python -m pytest` and `ruff check src tests` before opening a pull request.

Maintainers triage new issues within two business days. Issues that describe
several independent problems may be split into follow-up items by the triage
assistant.
